# RSIダイバージェンスと流動性ゾーンのシグナル仕様

## 目的と位置付け

既存の流動性ゾーンを環境認識に用い、事前に形成された帯付近で価格とRSIが逆行した場合に、確定後のエントリー候補を通知する。シグナルは注文、反転、利益、または優位性を保証しない。既存のゾーン表示・生成条件は、この機能を追加しただけでは変更しない。

対応対象は4時間足を含む時間ベースの通常チャートとする。RSIと価格ピボットは表示中のチャート足で計算する。非標準チャートと時間ベース以外ではシグナルを出さず理由を表示する。15分を超えるチャートでは既存のゾーンを使用し、下位足の全ピボットを取得できないほか、履歴とリアルタイムの再現性は未保証である。

## 価格とRSI

- 終値のRSIを使い、価格の `low` と `high` でそれぞれピボットを検出する。価格ピボットのバーのRSIを比較し、RSI自体のピボットは要求しない。
- 左4本・右2本を初期値とする。左右のバー数は設定可能とし、右側の確認バーが確定したとき初めてピボットを扱う。
- 同方向の直前の価格ピボット1件と比較する。強気は今回の安値が前回より低く、今回のRSIが前回より高く、前回のRSIが35以下の場合。弱気は今回の高値が前回より高く、今回のRSIが前回より低く、前回のRSIが65以上の場合。大小比較は厳密とする。
- 同方向ピボット間隔の初期値は5〜40バーで、両端を含む。間隔が範囲外でも今回のピボットを次回の比較基準として記録する。過去の都合のよいピボットを探索しない。
- 必要なRSI、価格または過去のピボットが存在しない場合は不成立とする。`minDivergenceBars > maxDivergenceBars` ではシグナルを停止し、無効設定であることを表示する。

RSI期間14、閾値35/65は検証の出発点であり、相場や銘柄に対する最適値ではない。強いトレンドでは逆張りが連続して失敗する可能性がある。

直前RSIの水準条件は設定で解除できる。解除時も価格とRSIの方向の逆行、間隔、および有効なゾーン設定は維持する。条件解除が優位性を改善するかは検証が必要である。

## ゾーンとの一致

### 利用可能な情報

価格ピボット候補バーを P、確認バーを C とする。Pの開始前に確定していた情報による有効ゾーンだけを、Pの確定時の価格と照合する。Pまたはそれ以降に確定した証拠は、Pの判定に使用しない。これにより、今回のピボット自身による帯の生成や強化を一致の根拠にしない。

各チャートバーの確定処理では、当該バーの証拠をゾーンに取り込む前の状態を参照し、当該バーの高値・安値に一致する候補の境界、役割、スコア、時間足構成、ATRなどを判定用に記録する。必要な履歴は右側確認本数に応じて保持する。既存のゾーン自体は凍結せず、通常どおり更新・統合・無効化する。

バーの開始時点と上位足の確定時点が一致する場合は、その上位足の確定値がチャートバー開始前に確実に利用可能であることを確認できたときのみ採用する。実装とReplayの検証でこの順序を一意に保証できない場合は、より古い確定値を使用する。

### 条件と候補選択

Pの `low` または `high` が、凍結した帯の上下限をそれぞれ `0.35 × 確定済み15分ATR` だけ拡張した範囲に入ることを近接とする。ATRはPの開始前に利用可能な値を固定し、`na` または0以下ならゾーン一致は不成立とする。0.35は**シグナルの近接距離**であり、既存のゾーン統合距離や無効化バッファを変更しない。

- 強気は支持または中立、弱気は抵抗または中立の有効ゾーンを対象とする。中立は方向を保証しない。
- スコアはP開始前の値で、シグナル専用の最小スコア以上とする。初期値は2.0。表示用の `minimumScore` とは独立する。
- 初期設定では1時間足・4時間足・日足のいずれかの確定証拠を必須とする。これはチャート足に対する相対的な上位足という意味ではなく、複数時間足の独立性や強さを保証する条件でもない。
- 描画件数や重複抑制による非表示ゾーンも照合する。表示設定によって結果を変えないためであり、非表示の帯によるシグナルがあり得る。
- 複数の帯が該当する場合、各帯を独立に破綻判定する。条件をすべて満たす帯のうち、Pの価格と帯との距離が最小のものを採用する。帯内の距離は0とし、同距離ならスコアの高い帯、さらに同点なら下限価格・上限価格の順に小さい帯を採用する。同一条件の帯はどちらでも結果は同じとする。最初の帯が破綻していても、別の有効な帯があれば採用可能とする。

検証用の診断では、採用帯の上下限、役割、スコア、時間足構成、ピボット時刻と確認時刻を確認できるようにする。現在のチャートに残る帯は更新後の状態であり、過去の判定に使った凍結値と一致するとは限らない。

### 確認期間中の破綻

PからCまでの各バーの確定終値を、P開始前の帯とATRに対して検査する。両端を含め、強気は一度でも `close < bottom - ATR × invalidationBufferAtr`、弱気は一度でも `close > top + ATR × invalidationBufferAtr` なら、その帯は今回のシグナルに使用しない。等値は破綻に含めない。バッファの初期値は既存設定の0.15を使用する。

ヒゲによる一時的な突破は許容するが、終値で破綻した後の再侵入は救済しない。既存の中立ゾーンは両方向への終値突破で無効化される一方、このシグナル用判定は方向に不利な側のみを見る。確認時点で既存ゾーンが統合・削除されていないことは要求しない。この違いを診断情報で説明可能にする。

## 確定・表示・アラート

- Cの `barstate.isconfirmed` を満たしたときだけ結果を確定する。売買候補の `plotshape` とアラートはCに表示し、Pへ `offset` しない。
- シグナルは確定足の情報から得た候補であり、バックテスト上もCの過去や終値での約定を無条件に仮定しない。次バー始値など、明示した実行可能な価格とコストを使う。
- ゾーン一致を無効にした比較モードではRSIダイバージェンス単独で通知する。表示・アラート文言はゾーン一致を断定せず、両モードを区別する。
- ピボットから確認までに価格が大きく離れると、帯での反応を検出していても確認時のエントリー条件は悪化し得る。PとCの価格距離、帯までの距離を診断対象とし、確認価格の距離制限は初版では必須条件にしない。距離フィルターは別の仮説として比較検証する。
- シグナルは `plotshape` で描画し、`label.new` の上限を消費しない。診断用の描画を追加する場合は別途リソース上限を設ける。

## 実装前提

1. ゾーン統合時の時間足マスクは、複数ビット同士でも各時間足の和集合となるよう修正する。例: `4` と `12` の統合結果は `12`。1時間足以上の有無も各ビットで検査する。
2. 上位足のピボット、ATRなど、判定とゾーン状態に影響する入力は、履歴とリアルタイムで対応する同じ確定値を使う。`lookahead_off` やチャート足の確定判定だけでは未確定の上位足を排除できない。同一足と上位足を区別し、1分足の重複収集とチャート足の時間足誤分類を防ぐ。
3. 15分ATRは15分未満のチャートでは確定済み15分足、15分チャートでは確定済みの先行15分足を、P開始前の情報として使用する。15分を超えるチャートの照合では前のチャート足に取得した15分ATRを使用する。下位足データの制約により再現性は未保証。ATRが得られない場合は無理に代替しない。
4. 照合用の記録は値のコピーとし、可変のゾーン参照を後から変更して過去の判定が書き換わらないようにする。候補数は既存ゾーン数と右側確認本数で上限を設ける。
5. ゾーン一致と1時間足以上の証拠をともに必須とするモードは、1時間足・4時間足・日足の証拠収集をすべて無効にした状態では条件を満たせない。設定状態を診断可能にする。単に低時間足の重みを0にしても、その証拠の収集やゾーン形成が無効になるわけではない。

## 撤退候補

ゾーン一致のBUY後は採用帯下限とPの安値の低い方から15分ATRの0.35倍を引いた基準を、SELL後は帯上限とPの高値の高い方に同じ幅を足した基準を固定する。基準を不利な方向へ2本連続の確定終値で超えると、対応する撤退候補を1回表示し追跡を終了する。途中で基準に戻った場合は連続回数を0に戻す。幅と確認本数は設定可能。初期値は検証用の仮説であり、利益化確率は算出しない。

仮想ポジションはBUYまたはSELLの1件のみで、同方向の新規サインは表示せず既存の基準を上書きしない。反対サインが成立したときは `REV BUY` / `REV SELL` を出して追跡を終了し、その足では反対方向の追跡を開始しない。ポジションなしのときに両方向が同時成立した場合は見送る。

利確目標はCのゾーン更新後に、有効で進行方向にある反対側または中立の帯から、Cの終値に最も近い境界を選択し固定する。BUYは抵抗または中立帯の下限が終値より上、SELLは支持または中立帯の上限が終値より下であることを要求する。表示の有無やスコアでは絞り込まない。対象がない場合は目標なしとする。Cの次の足以降に高値または安値が目標に到達した場合、その足の確定時に `TP BUY` / `TP SELL` を表示して追跡を終了する。確定後にゾーンが変化しても目標は変更しない。

同一足で複数の終了条件が成立した場合、撤退、利確、反対サインの順に優先する。足の中の到達順は不明であり約定結果ではない。撤退判定を無効にすると基準による追跡終了は停止するが、利確・反対サインは有効。実際のポジションや手動決済は参照できず、RSI単独モードでは撤退基準なしで利確と反対サインを追跡する。確定待ちによる損失拡大やギャップに注意する。

## 仮想成績と診断表示

診断表は「直近シグナルの診断」で表示し、「診断の詳細表示」がオフならP/C、帯、役割・スコア・時間足、PからCの距離、Cから帯の距離、RSI候補、最終サインの各行を隠す。詳細をオンにするとこれらを表示する。

仮想PFと勝率は読み込まれた履歴内の決済済み仮想ポジションだけを集計する。エントリーと決済のサインが確定した足の終値を使用し、買いは決済終値からエントリー終値を引き、売りはその逆とする。各取引の数量は同一と仮定し、価格差のプラス分の合計をマイナス分の絶対値の合計で割ったものがPFである。損失なしで利益がある場合は「損失なし」、利益と損失がともにゼロなら「-」とする。勝率は損益が正の決済件数を全決済件数で割る。損益ゼロも分母に含み、未決済は含めない。

利確サインは目標への到達を足の高値・安値で判定するが、成績評価は決済足の終値で行う。目標到達後に価格が戻れば、利確サインでも評価上の損失があり得る。スプレッド、手数料、スリッページや実際の注文を考慮しないため、実現損益や実行可能な成績を保証しない。履歴の範囲やデータ再現性の制約によって数値は変わる。

## 検証計画

### 因果関係と実装

| ケース | 期待結果 |
| :--- | :--- |
| P以降に初めて作られた帯、またはHTF証拠を追加した帯 | P以前の情報では条件を満たさないなら不成立 |
| P時点で2帯が該当し、近い帯のみ破綻 | 他方が残りの条件を満たせば成立 |
| PからCまでの途中足でバッファ外に終値、次足で再侵入 | 不成立 |
| ヒゲのみバッファ外、終値はバッファ以内 | 破綻条件だけでは不成立にならない |
| Cの形成中と確定後 | 形成中は通知せず、確定時のみ通知 |
| 上位足の切り替わり、セッションの間隔、ATR不足 | P開始前に利用可能な確定値のみ使用し、欠損時は不成立 |
| 同一データと履歴開始位置でリアルタイム確定後に再読み込み | シグナル、採用帯と判定値の一致を確認。下位足取得を伴う場合の一致は保証しない |
| 時間足マスク `4` と `12` の統合 | `12` となり、1Hと4Hの証拠が残る |
| 表示ゾーン数・表示最小スコア・重複抑制の変更 | 内部ゾーンが同じならシグナルは変わらない |

データ配信元の訂正、履歴開始位置、取引セッション設定、スクリプト設定が異なる場合まで再現性を保証しない。TradingViewのリアルタイム、Bar Replay、再読み込みを実際に比較する。

### 統計・実戦

銘柄、時間足、期間、執行タイミング、決済、損切り、最大保有時間、同時シグナルの扱い、スプレッド・手数料・スリッページを事前に固定する。次の三群を同じルールで比較する。

1. 価格ピボット基準のRSIダイバージェンス単独。
2. 事前形成ゾーンとの一致を追加。
3. さらにPからCまでの破綻除外を追加。

発生件数、候補からエントリーまでの価格変化、期待値、損益分布、ドローダウン、時間帯・トレンド環境別の成績を確認する。連続シグナルや複数時間足に由来する同一局面は独立標本として扱わず、期間外データやウォークフォワードで再検証する。値の調整回数と比較対象を記録し、勝率だけで結論を出さない。

前提としてXAUUSDの出来高はフィードによりティック出来高の場合がある。出来高の増減だけを買い圧力・売り圧力の方向判定やRSIの代替とはみなさない。ニュース時の取引制限、トレンド判定、確認時の追いかけ防止、反対側ゾーンまでの余地は有力な追加仮説だが、初版の必須条件とせず別々に評価する。
