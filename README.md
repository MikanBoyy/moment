# moment

TradingView Pine Script v6 indicator の開発リポジトリです。水平流動性ゾーンとRSIダイバージェンスのコンフルエンスを表示します。

## 構成

- `src/domain/`: domain層
- `src/application/`: ユースケースと状態の統合
- `src/presentation/`: 設定と描画
- `src/main.pine`: indicator の入口
- `scripts/`: ビルド
- `dist/`: 自動生成された貼り付け用 Pine Script（Git 管理外）

依存方向は `presentation -> application -> domain` とします。

RSIダイバージェンスの検出は `src/domain/rsi_divergence.pine`、ゾーンとの照合・利確目標・仮想ポジション・仮想成績の更新は `src/application/`、売買サインと診断テーブルは `src/presentation/` に分けています。Pineのグローバルスコープ制約により、各モジュールは `src/main.pine` で実行順に結合します。

決済時の価格差から利益・損失・勝敗を求める共通計算は `src/domain/trade_performance.pine`、RSI用と市場構造用の成績更新は `src/application/signal_performance.pine` に置いています。市場構造の売買サインとアラートは `src/presentation/structure_trade_renderer.pine`、状態表は `src/presentation/market_structure_renderer.pine` で扱います。

## ビルド

Python 3.10 以降を使います。外部パッケージは不要です。

```powershell
python scripts/build.py
```

`dist/moment.pine` を TradingView の Pine Editor に貼り付けて確認します。すべての `.pine` ファイルは UTF-8（BOM なし）で保存してください。

## マルチタイムフレーム流動性ゾーン

1分・15分・1時間・4時間・日足の fractal pivot とチャート足のピボットを収集し、近い価格を ATR 基準の帯へ集約します。チャート足と同一時間足の証拠は重複収集しません。5分足チャートのピボットは15分足と区別し、1分足と15分足の重みの平均で採点します。チャート足より下位の `request.security` は全ての下位足を収集できるわけではありません。

ゾーンのスコアは次の証拠を合算します。

- 時間足の重み: 初期値は 1分=1、15分=3、1時間=5、4時間=8、日足=13
- 同一ゾーンに集まる確定ピボット数と追加反応
- ピボットからの経過時間による減衰
- 利用できる場合だけ加える相対ティック出来高

強いゾーンは帯と中心線で表示します。確定終値がゾーン外側を ATR バッファ分だけ抜けると、ゾーンは点線・減光表示へ変わり、設定した保持時間を経て削除されます。出来高が存在しないデータフィードでも、価格と時間足の証拠だけでゾーンを評価します。

## TradingView 検証

1. `dist/moment.pine` を Pine Editor に貼り付け、任意の XAUUSD チャートへ適用します。1分足では5つすべての時間足を、5分足以上では15分足・1時間足・4時間足・日足を集計します。
2. Bar Replay で15分・1時間・4時間・日足の終値をまたぐ地点を確認します。各上位足のピボットに基づくゾーンは、該当する上位足が確定するまで出現してはいけません。
3. 1分足だけの単独ピボット帯と、複数時間足で重なる帯を比較します。後者が高いスコアで表示されることを確認します。必要なら「スコアラベル」を有効化します。
4. ゾーン境界を終値で越える場面を Replay し、対象の帯と中心線が減光・点線化すること、保持時間後に消えることを確認します。
5. 長い履歴を表示し、入力した「候補ゾーン上限」「表示ゾーン数」を超えてオブジェクトが増えないことを確認します。

## RSIダイバージェンス

4時間足を含む時間ベースの通常足で、価格ピボットとそのバーのRSIを前回の同方向ピボットと比較します。事前に形成された有効ゾーンとの一致を初期設定で必須とし、確認期間中に帯を不利な方向へ終値で抜けた候補を除外します。サインとアラートはピボット位置ではなく確認足の確定時に発生します。直前RSIの35/65条件は設定で解除できますが、サインの精度は保証されません。

設定でゾーン一致を無効にすると、RSIダイバージェンス単独の比較モードになります。このモードでは基準帯がないため撤退サインは出ません。別のRSI指標はピボット定義が異なる場合があり、候補件数は一致しません。表示対象外の内部ゾーンが採用される場合があります。

「直近シグナルの診断」を有効にすると、RSI用・市場構造用・両者を合算した仮想PFと仮想勝率を含む診断表を表示します。合算は両方の総利益・総損失・勝数・決済数をそれぞれ合計して計算し、同時保有も別々の取引として数えます。「診断の詳細表示」を有効にすると、P/C、採用帯、距離、RSI候補・最終サインの件数も表示します。詳細は初期状態では非表示です。

仮想PFと勝率は、読み込まれた履歴で決済された仮想ポジションを対象に、エントリーサインと決済サインの各確定足の終値で算出します。全取引を同じ数量として価格差を合計し、PFは総利益を総損失の絶対値で割ります。総損失がゼロで総利益がある場合は「損失なし」、両方ゼロなら「-」です。勝率は利益が正の決済数を損益ゼロを含む全決済数で割ります。未決済は除外し、スプレッド・手数料・スリッページは考慮しません。利確は目標到達価格ではなくサイン確定足の終値で評価するため、目標到達後に価格が戻れば損失になることもあります。実際の約定やバックテストの成績ではありません。

仮想ポジションは買い・売りのいずれか1件だけを追跡します。保有中に同方向のサインが再発した場合、初回エントリー足の確定終値より不利な価格なら `AVG BUY` / `AVG SELL`、有利な価格なら `PYR BUY` / `PYR SELL` を表示します。同値では表示しません。追加サインは設定で無効にでき、個別のアラートも利用できます。数量や平均取得価格を追跡せず、追加分は仮想成績、撤退・利確基準に反映しません。実際のポジションや約定価格とは異なります。

反対サインでは `REV BUY` / `REV SELL` を表示して追跡を終了し、同じ足で反転エントリーしません。撤退・利確・反対サインが同じ足で成立した場合は追加サインより優先します。ポジションがないときに買いと売りが同時成立した場合は両方を見送ります。

利確候補はエントリー確定時の価格から進行方向で最も近い反対側または中立の有効ゾーンとし、買いは帯の下限、売りは上限を固定します。帯のスコアや表示設定では絞り込まないため、非表示の帯が対象になることもあります。エントリー足の次の足以降に高値・安値が目標へ到達した場合、その足の確定時に `TP BUY` / `TP SELL` を表示して追跡を終了します。該当する帯がない場合、目標は設定されません。

ゾーン一致サインの撤退候補は、買いでは採用帯の下限とピボット安値の低い方、売りでは帯の上限とピボット高値の高い方に、記録した15分ATRの0.35倍を外側に加えた価格を基準とします。初期値では、その価格を不利な方向へ2本連続の確定終値で超えると撤退サインを出します。幅と本数は設定可能です。撤退判定を無効にしても利確・反対サインによる追跡終了は続きます。RSI単独モードでも利確と反対サインは追跡しますが、撤退基準は設定されません。

同じ足で複数の終了条件が成立した場合は、撤退、利確、反対サインの順に優先します。足の中で価格がどちらに先に到達したかは分からず、サインは約定を意味しません。実際のポジションや約定価格は参照せず、手動で取引を終了しても追跡は終了しません。サイン発生前からのポジションも対象外です。

撤退の基準は利益化確率を推定したものではなく、注文・損切り・決済も行いません。確定を待つ間の急変、ギャップ、スリッページで大きく損失が拡大する可能性があります。15分を超える時間足では下位足の全ピボットを収集できず、ゾーンやサインが履歴とリアルタイムで一致しない可能性があります。

仕様と検証条件は `docs/rsi-divergence-confluence.md` を参照してください。実運用前に TradingView のコンパイル、Bar Replay、リアルタイム確定後の再読み込みと、コストを含む期間外検証が必要です。

## 市場構造

チャート足の確定ピボットの高値・安値が両方切り上がれば上昇、両方切り下がれば下降を初期方向とします。いったん方向が決まると、ピボット比較が混在しても方向を保持します。押し安値・戻り高値が事前形成された有効帯に接触し、その後に高値・安値を確定終値で突破した場合、その帯を構造上の基準帯として記録します。基準帯を確定終値で超えると注意、記録したATRによるバッファをさらに超えると方向の終了候補とします。終了と同時に反対方向が成立するわけではありません。左上に状態、直近ピボット、基準帯と突破待ち帯を表示します。

市場構造用のピボット強度、終了バッファ、候補の有効期間は独立して設定できます。基準帯がない間は、前足までに確定した直近ピボットと前足のチャート足ATRを代替基準として終了を判定します。基準値が不足する場合は終了判定を行えません。

最後に成立した市場構造から反対方向が成立した確定足に、上昇から下降なら「構造 SELL」、下降から上昇なら「構造 BUY」を表示します。判定保留を挟む反転も対象ですが、初回の方向成立や同方向への復帰では表示しません。サインの表示設定は市場構造の表と独立しており、既存のRSIシグナル、仮想ポジション、成績には影響しません。通常の時間ベースのチャートを対象とし、下位足取得による再現性の制限や、条件の詳細・検証手順は `docs/market-structure.md` を参照してください。

構造用の仮想ポジションはRSI用とは別に1件を追跡し、構造終了または反対方向への直接反転で撤退候補を表示します。エントリー時に最も近い反対側または中立の有効ゾーンを利確目標に固定し、次の足以降に到達すると利確候補を表示します。目標帯がない場合は利確目標を設定しません。利確と撤退が同じ足で成立した場合は撤退を優先します。基準不足の間は構造終了を判定できず、固定ストップも設けていません。サインは実際の約定や利益を保証しません。
